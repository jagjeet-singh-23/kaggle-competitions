# SED Branch Pilot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train one HGNetV2-B0 SED fold on Kaggle GPU with the public pseudo-labels, blend it with the Perch kernel, and decide go/no-go on the LB.

**Architecture:** A local script builds a compact int16 audio cache from the SSD and uploads it as a private Kaggle dataset. Only *which* windows are in the cache is fixed there; the targets live in separate files, so Phase B can swap labels without touching anything else. A Kaggle GPU kernel trains on the cache and saves EMA weights. Locally, those weights are exported to ONNX and parity-checked. A new submission kernel runs Perch and SED on the same windows, rank-blends them, and smooths.

**Tech Stack:** PyTorch 2.14 (MPS locally, CUDA on Kaggle), timm `hgnetv2_b0.ssld_stage2_ft_in1k`, ONNX + onnxruntime 1.24.4 (CPU), numpy/pandas/sklearn, Kaggle CLI 2.2.4.

**Spec:** `BirdCLEF/docs/superpowers/specs/2026-10-20-sed-branch-design.md`

**Scope:** This plan covers the pilot and the go/no-go decision only. Phase A full and Phase B get their own plans once the pilot numbers are in.

  - dB with top_db 80

- Recipe:

  - mel mixup (alpha 1.0), AMP, EMA (`timm.utils.ModelEmaV3`, decay 0.999)
  - loss `0.5·BCE(clip_logits) + 0.5·BCE(max_t frame_logits)`
- **Leakage rule:** no pseudo-label row whose `fold_id != -1` (the 66 labelled files) ever enters training. Those files contribute only their true labels.
- **A/B rule:** the pseudo-window selection is a function of `row_id` and a seed only, never of any teacher's values. Targets are stored per teacher (`pseudo_targets_A.npy`).

- Blend: per-class tie-aware rank `(1-w)·rank(perch) + w·rank(sed)` with `W_SED = 0.5`, then kernel v4's smoother (k=6, max, alpha=0.2).
- Go/no-go: the blend's private LB must be ≥ **0.9318** (0.92681 + 0.005).

- Kaggle uploads are staged under `/Volumes/Extreme SSD/kaggle/BirdCLEF/jobs/`. Copy with `cp -X`, and run `find -name '._*' -delete` before every upload.

## Review Focus

1. **Front-end drift between training and inference.** The cache stores int16, but inference reads float from ogg. Expect `cache/32767` to match the soundfile float within 1/32767, and the kernel to use the same `LogMel` module as training. Test: Task 2 roundtrip; Task 5 parity check (kernel SED output vs training-time eval output on the same cached windows).
2. **Labelled files leaking in through the pseudo-labels.** Expect zero of the 66 labelled filenames in `pseudo_meta.csv`. Test: Task 2 selftest.
3. **Perch and SED rows misaligned in the blend.** Expect both branches to score the same `row_id` list in the same order. Test: Task 5 asserts equal row_ids before blending.
4. **Short or stereo test files.** Expect SED to get exactly the windows Perch gets (`perch.to_windows`, zero-padded tail, channels averaged). Test: Task 5 local run includes one truncated stereo file.
5. **The kernel overrunning 90 minutes on the hidden test.** Expect the smoke run to log a projection for 600 files that stays under 75 min. Test: Task 5, step "Kaggle smoke run".

**Files:**
- Create: `BirdCLEF/sed_model.py`
- Modify: `requirements.txt` (add the pinned `timm`, `onnx` and `onnxscript` versions that get installed)

**Interfaces:**
- Produces:
  - `LogMel(nn.Module)`: `forward(wave: Tensor[B, 160000] float32 in [-1, 1]) -> Tensor[B, 1, 256, 512]`. dB values, normalised per sample to zero mean and unit variance.
  - `SED(nn.Module)`: `__init__(backbone: str = "hgnetv2_b0.ssld_stage2_ft_in1k", n_classes: int = 234, pretrained: bool = True)`, `forward(mel) -> (clip_logits [B, 234], frame_logits [B, T', 234])`.
  - `sed_loss(clip_logits, frame_logits, y) -> Tensor`
  - `export_onnx(model: SED, path: str) -> None`. Input `mel` [B, 1, 256, 512] with a dynamic batch; output `prob` [B, 234], which is `sigmoid(clip_logits)`.

- [ ] **Step 1: Install deps.** Run `uv pip install --python $PY timm onnx onnxscript`, then pin the installed versions in `requirements.txt` under the BirdCLEF comment.
- [ ] **Step 2: Write the failing selftest** `sed_model.selftest()`. It must assert:
  - `LogMel()(torch.zeros(2, 160000)).shape == (2, 1, 256, 512)`, and the output is finite.
  - A 4 kHz sine at amplitude 0.5 has its time-averaged peak at the mel bin closest to 4 kHz on the HTK scale (`2595·log10(1 + f/700)`, 256 bins from 20 to 16000 Hz), within ±1 bin.
  - `SED(pretrained=False)` on `LogMel()(torch.randn(3, 160000))` gives `clip_logits.shape == (3, 234)` and `frame_logits.shape[0] == 3`, `frame_logits.shape[2] == 234`.
  - Clip logits lie within `[min_t frame_logits, max_t frame_logits]` for every class (attention pooling is a convex combination).
  - `sed_loss` with `y = 0` and all logits `= -20` is `< 1e-6`.
  - After `export_onnx` to a temp path, onnxruntime on the same mel gives `|ort - sigmoid(torch clip_logits)| < 1e-4`.
- [ ] **Step 3: Run it to see it fail.** `cd BirdCLEF && $PY sed_model.py --selftest`. Expected: ImportError or NameError.
- [ ] **Step 4: Implement.**
  - `LogMel` is built from `torch.stft` with a Hann window of `win_length`, plus a mel filterbank built once in numpy (HTK scale, Slaney area normalisation) and registered as a buffer. Do not depend on torchaudio, which is absent locally.
  - dB is `10·log10(clamp(power, 1e-10))`, clamped at `max - 80` per sample, then normalised per sample.
  - `SED` takes the timm backbone with `features_only=False, num_classes=0, global_pool=""`. Mean over frequency gives [B, C, T']. A 1×1 conv projects to 512 with ReLU and dropout 0.3. Two 1×1 conv heads, `att` and `cla`, map to 234. `clip = Σ_t softmax_t(tanh(att))·cla`.
- [ ] **Step 5: Run the selftest to see it pass.** Expected: `sed_model self-checks passed`.
